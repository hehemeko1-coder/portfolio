I learn by making. That means taking ideas from rough structure to interface, from interface to implementation, and from a first working version through iteration. My work includes AI products, social platforms, website experiences, and graphic design.

I care about clear thinking, useful systems, strong visual hierarchy, and the details that make a product coherent. This portfolio is a record of real work in progress—not a list of titles or claims without evidence.

04 / HOW I APPROACH THE WORK

Behind the interface.
Inside the decisions.

A portfolio should show more than a finished screen. Explore the problem space, the system I worked on, and the next engineering questions for three projects.

AI PRODUCT · FULL-STACK BUILDCASE 01 / 03

Ânimo AI — building a useful assistant, not just a chat box.

The project grew from a simple conversational interface into a broader AI application. The challenge was to connect model access, useful tools, documents, image understanding, and memory into one coherent product experience.

THE PROBLEM SPACE

A chat interface alone is not a complete assistant. It needs context, useful capabilities, and a dependable way to preserve information between sessions.

WHAT I BUILT

An application with configurable AI providers, web search, document and image input, and persistent memory backed by PostgreSQL.

ENGINEERING FOCUS

Connecting the user experience to provider configuration, server-side features, and persistent data rather than treating each capability as an isolated demo.

NEXT QUESTIONS

How should memory be evaluated? How can retrieval be made transparent? What test suite would protect tool use, provider failures, and long conversations?
